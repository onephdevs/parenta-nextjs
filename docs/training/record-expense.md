# Job: Record a building expense

**Replaces:** A cash-out row in Excel (salary, repair, fuel, cleaning).

**Who does this:** Office admin / Owner

**When:** You paid a vendor or staff and need it on the month’s cash-flow.

## Steps
1. Sidebar **Bills & Expenses** → **Expenses** (`/admin/financial/expenses`). Click **Record Expense**.
2. **Amount:** enter **Amount**. **Category:** choose **Category** and **Description**. **Date:** set **Expense Date**.
3. Optional: **Building**, **Unit / Room**, **Vendor**. Click **Record Expense**.

## Also on this page
**Expenses list**
- Cards: **Total Amount**, **This Month**, **Top Category**, **Average**.
- **Search** — **Description or vendor...**
- Filters: **Category** (**All Categories**), **Building** (**All Buildings**), **Vendor**, **From Date**, **To Date**.
- Table **Actions** → **View**. No export on this list. No bulk. No sort UI called out.
- Empty: use **Record Expense**.

**Record Expense form**
- Sections: **Amount**, **Category**, **Date**, **Location**, **Vendor**, **Notes**.
- **Category** options: **Cleaning**, **Maintenance**, **Repair**, **Upgrade**, **Garbage collection**, **Food allowance**, **Fuel / diesel**, **Staff salary**, **Refund**, **Cash allowance**, **Other**.
- **Vendor** can be **Add vendor** / type a name.

**Expense detail** (`/admin/financial/expenses/[id]`)
- **Edit Expense** (`.../edit`). **Delete** — confirm **Delete expense?** / **Delete this expense? This cannot be undone.**

**Related**
- Counts in **Disbursement / Cash-flow**.
- Tasks **Building expenses** board is follow-up, not the ledger.
- Utility bills are a different list — do not record Meralco splits here.

## Done when
You land on the expense detail. After refresh it appears on **Expenses**. It will count in **Disbursement / Cash-flow**.

## Watch out for
**Amount must be greater than 0.** Pick a **Category** that matches the spend (e.g. **Staff salary**, **Food allowance**).
