# Job: Pull a collections or occupancy report

**Replaces:** Asking the accountant to rebuild Excel pivots for occupancy, deposits, or vacant rooms.

**Who does this:** Owner / office admin

**When:** You need a printout or a period total that is not the unit × month desk or the disbursement waterfall.

## Steps
1. Sidebar **Reports** (`/admin/reports`). Search **Report name...** or set Category (not **All categories**).
2. Open the report (names below). Set its date / property filters.
3. Use **Generate**, **Print**, **Export Excel**, or **Export PDF** if that report shows them.

## Also on this page
**Hub**
- Categories: **Financial Reports**, **Property Reports**, **Tenant Reports**, **Asset Reports**, **Utility Reports**, **Analytics & Insights**.
- No bulk. Hub itself has search + category filter only.

**Financial (besides unit × month and disbursement)**
- **Collected Amount Report** — received by month/quarter/six months/year (`/admin/reports/collected-amount`).
- **Portfolio Rollup** — Balibago vs Villasol occupancy and collections (`/admin/reports/portfolio`).
- **Deposit Report** — deposits on hand (`/admin/reports/deposits`).
- **Expense Report** — **Export Excel**, **Export PDF**, **Print** (`/admin/reports/expenses`).
- **Comprehensive Financial Report** / **Revenue Report** / **Expense Analysis** / **Rent Roll Report** / **Profit & Loss Statement** → `/admin/financial/reports` (and `?type=` variants). Payments child **Reports & Analytics** is the same family.

**Property / tenant**
- **Vacant Rooms Report** (`/admin/reports/vacant-rooms`).
- **Occupancy Report** / **Building Performance** / **Payment Patterns** → Analytics.
- **Room Status Report** → `/admin/rooms` (not in sidebar).
- **Tenant List Report** — balances and past due (`/admin/reports/tenant-list`).
- **Tenant Summary** → Tenants list.
- **Outstanding Balances** → Payments with pending status.

**Other**
- **Utility Bills Summary** → `/utilities` (older utilities dashboard).
- **Cost Allocation Report** / **Meter Readings** — those office jobs.
- **Data Export** → `/admin/export`.
- **Advanced Financial Analytics** → `/admin/financial/advanced-analytics`.
- Bills & Expenses → **Reports** — utility + expense spend, Excel/PDF/print.

**Financial Dashboard** (`/admin/financial/dashboard`) — charts (revenue, occupancy, upcoming dues), not a printable ledger.

## Done when
The figures match the period you set. After refresh, generate again — most reports do not store a snapshot.

## Watch out for
Pick the same **From** / **To** (or month range) you use in Excel. Admin units are excluded from some collection views.
