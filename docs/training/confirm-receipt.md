# Job: Confirm a tenant’s uploaded GCash receipt

**Replaces:** Checking a screenshot in Messenger, then ticking Excel.

**Who does this:** Office admin / Owner

**When:** The tenant used **Pay now** or **Upload receipt** in the portal, and **Payments** shows **Pending verification**.

## Steps
1. Sidebar **Payments** (`/admin/financial/payments`). Under **Pending verification**, open the tenant’s row (badge **Pending**).
2. Check the attached receipt photo if there is one. Click **Confirm payment**.
3. Optional: type the **GCash / bank reference**. Click **Confirm received**. Use **Reject** only if the claim is wrong.

## Also on this page
**Payments list (same screen as Collect rent)**
- Card **Pending verification** — **Receipts waiting for office confirmation**.
- Section copy: **Cross-check the receipt if one is attached, then confirm. Reference number is optional for now — ledger imports often have none.**
- Compact **Confirm** / **Reject** may appear on the hub; full labels **Confirm payment** / **Reject** on the receipt.
- Search, filters, pagination — see **Collect rent**. Invoice balances do **not** change until you confirm.

**Payment detail**
- Alert **Awaiting verification**.
- **Confirm payment received** dialog: invoice / transaction / reference lines; **GCash / bank reference (optional)**; **Confirm received**.
- **Reject payment claim** → **Reject**.
- **Tenant conversation** — **Message the tenant…**; needs a message or photo.
- **Uploaded receipt** / **Download proof**.
- After confirm, **Refund** / **Void** apply like office-recorded payments.

**Not this job**
- **Process Payment** is for cash you enter yourself.

## Done when
Toast **Payment confirmed**. After refresh the row is gone from **Pending verification**, and the invoice shows **Paid** (or **Partially paid**).

## Watch out for
**Confirm payment** only appears while status is **pending**. If a reference is already on file and you type a different one: **Reference mismatch** — leave the box blank to confirm anyway.
