# Job: Export a spreadsheet for the accountant

**Replaces:** Copy-paste from Excel into another workbook.

**Who does this:** Owner / office admin

**When:** The accountant needs CSV / Excel / PDF / JSON. Open from Reports hub **Data Export**, or Settings → System **Export Data**. URL `/admin/export`.

## Steps
1. Open **Advanced Export** (`/admin/export`).
2. Choose the data set and format (**CSV**, **Excel**, **PDF**, or **JSON** as offered).
3. Run the export and save the file.

## Also on this page
- Not in the sidebar. Custom column/format options live on this page.
- Some reports have their own **Export Excel** / **Export PDF** / **Print** (Expense Report, Bills & Expenses Reports, tenant **Statements**).
- Payments list has **no** export.

## Done when
The file opens with the rows you expect. Re-run after a refresh if you just recorded payments.

## Watch out for
Pick the same date range as the ledger. A PDF of the wrong module is not a substitute for **Disbursement / Cash-flow**.
