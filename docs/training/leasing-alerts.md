# Job: Warn which leases expire soon

**Replaces:** A calendar note of end dates.

**Who does this:** Office admin

**When:** Monthly, before terms run out.

## Steps
1. Sidebar **Leasing** (`/admin/leasing`). Open **Expiration alerts**.
2. Click **Generate Alerts**.
3. Work the list (renew or give notice). **Renewals** tab lists leases nearing end.

## Also on this page
- **All leases** / **Move-outs** — other jobs.
- Filters on **All leases**: **Status** includes **Expiring soon**.
- Generating alerts does not renew or vacate.
- No export/print of the alert list.

## Done when
After refresh, alerts match leases that are actually ending. You have opened **Renew** or **Terminate** for each one you will act on.

## Watch out for
**Generate Alerts** is a list, not a message to the tenant. **Notice given** is terminate-on-paper, not expiry.
