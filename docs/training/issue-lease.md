# Job: Issue or store a lease document

**Replaces:** Printed contract in a folder, or a signed PDF in Messenger / Drive.

**Who does this:** Office admin

**When:** After a tenant is assigned to a unit, or when a signed copy comes back.

## Steps
1. Sidebar **Tenants** → open the tenant → **Documents** (`/admin/tenants/[id]?tab=documents`).
2. Under **Upload / e-sign lease**, click **Generate lease** (draft from assignment and building policies) or **Upload** / **Upload signed PDF** (PDF, DOC, or DOCX, max 10MB).
3. If e-sign is needed, type the name, accept the terms, and click **Sign as landlord** (or **Sign lease**). Use **Regenerate lease** only if you must replace the file.

## Done when
**Lease Contract** under **Required Documents** shows the file after refresh. The tenant can open it under portal **Documents**.

## Watch out for
**Generate lease** needs an active room assignment. If a signed lease is already on file, the app asks to confirm replace before overwriting.
