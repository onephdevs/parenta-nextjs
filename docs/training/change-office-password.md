# Job: Change my office password

**Replaces:** Sharing one password on a sticky note.

**Who does this:** Office admin (your own account)

**When:** First login, or when you need a new password.

## Steps
1. Sidebar footer (your name/avatar) → `/admin/profile`. Or Settings → **Security** → **Change Password**.
2. On **Admin Profile**, edit name/photo if needed. Click **Save Changes**. Under **Change Password**, enter current and new passwords.
3. Click **Change Password**.

## Also on this page
- Profile photo. Name fields.
- Settings **Security** also has **Two-Factor Authentication** and **Session Timeout**.
- To reset someone else’s office login: **Users** → **Edit**.
- To reset a tenant: tenant profile **Reset password**.
- Forgot from sign-in: **Forgot Password?** → `/auth/forgot-password`.

## Done when
After **Sign out**, you can **Login** with the new password.

## Watch out for
New password must meet the form’s length rule and match confirm. Changing *your* password does not change tenant portal passwords.
