# Job: Design the lease PDF the office generates

**Replaces:** Editing a Word contract by hand every time the house rules change.

**Who does this:** Admin

**When:** The 1-page room rental agreement needs new clauses before you **Generate lease** for tenants.

## Steps
1. Sidebar **Documents** → **Lease Designer** (`/admin/documents/lease-designer`).
2. Edit **Clauses** (**Add clause**, **Text clause** / **Checkbox options** / **Utility allocation table**). Optional **Use compact template** (replaces all clauses with the compact Room Rental Agreement).
3. Click **Save draft** or **Publish…**. Check **Printable preview**; **Print** or **Export PDF**.

## Also on this page
- Page size **US Letter** / **A4**. Badges **Unsaved**, **V{n} · Published** / **Draft**.
- **Signatures** — **Print Name:**, **Upload image**. **Remove clause**.
- **Export Word** may show a stub message (PDF/print are the reliable outputs).
- Confirm **Use compact template** — unsaved edits are lost.
- **Documents** → **Templates** (`/admin/documents/templates`): search **Template name...**; **All Status** / **Published** / **Draft**; **Open Lease Designer**; **View**.
- Package terms (deposit months, grace, penalty) are **Lease Templates** under Leasing, not this designer.

## Done when
After refresh the template still shows your clauses. The next **Generate lease** on a tenant uses this layout.

## Watch out for
**Use compact template** wipes unsaved edits. Publish only when the office agrees the wording is final.
