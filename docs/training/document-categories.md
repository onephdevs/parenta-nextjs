# Job: Set document categories

**Replaces:** Folder names on a shared drive.

**Who does this:** Admin

**When:** Before filing IDs and contracts, if **Uncategorized** is not enough.

## Steps
1. Sidebar **Documents** → **Manage Categories** (`/admin/documents/categories`). Title **Document Categories**.
2. Click **New Category**. Fill **Category Name** (required). Optional: **Description**, **Parent Category (optional)** (**No parent (root category)**).
3. Click **Create Category**. Return to **Documents** and use **Category** on upload and filters.

## Also on this page
- Copy: **Organize your documents with categories for easier management and searching.**
- Empty: **No categories yet** / **Create Category**.
- List shows document count and **Created** date; nested names under a parent.
- No search, filter, sort, pagination, export, or print.
- **No Edit or Delete on this page** — you can only add categories here.
- Upload default **Uncategorized**. Library bulk **Categorize**.

## Done when
After refresh the new name is in the list and in the Documents **Category** filter.

## Watch out for
**Category Name** cannot be blank (**Create Category** stays off until it has text). There is no delete on this screen if you add a name by mistake.
