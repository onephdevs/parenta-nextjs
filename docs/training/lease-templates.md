# Job: Set lease template terms (deposit, term, penalty)

**Replaces:** A note in Excel of “2 months deposit, 1 month advance” copied onto every new occupant.

**Who does this:** Office admin

**When:** Before assigning rooms — Add Tenant and the pipeline pick from this list.

## Steps
1. Sidebar **Leasing** → **Lease Templates** (`/admin/lease-templates`). Click **Create Lease Template**.
2. Fill **Template Name**, **Lease Term** (3 / 6 / 12 Months / No Fixed Term), **Deposit Period**, **Advance Period**. Optional: **Grace Period (optional)**, **Penalty Type**, **Penalty Fee**.
3. Click **Confirm and Save**. On edit: **Save Changes**.

## Also on this page
- Search **Template name...** Filter **Applied**: **All templates**, **Assigned to units**, **Unused**.
- Row: **View**, **Edit**, **Delete**. Confirm **Confirm Deletion** — cannot be undone. **Unable to Delete** if still in use.
- This is not **Lease Designer** (PDF layout) and not **Documents → Templates**.

## Done when
After refresh the template is in the list. Add Tenant **Lease Template** dropdown shows it.

## Watch out for
**Template Name** is required. Do not delete a template still assigned to units.
