# Job: Split a metered bill by readings

**Replaces:** Spreadsheet formulas that divide one bill using last month’s meter numbers.

**Who does this:** Office admin

**When:** You have a total bill and meter readings, and equal-split on Utility Bills is not enough.

## Steps
1. Sidebar **Utilities** → **Cost Allocation** (`/admin/utilities/cost-allocation`). Choose **Building**.
2. **Allocation Rules:** set **Utility Type**, **Allocation Method**, optional **Include Common Area Costs**. **Save Rule**.
3. **Cost Calculator:** **Select Utility Bill**, method (**Equal Split**, **Usage-Based**, **Room Size**, **Custom Rules**), **Tenant Bill Due Date**. Click **Calculate Allocation**, then **Generate Tenant Bills**.

## Also on this page
- Tabs: **Overview**, **Allocation Rules**, **Cost Calculator**, **Tenant Bills**.
- Building search **Building name or address...** Empty: **Select a Building**.
- Overview explains **1. Configure Rules**, **2. Calculate Costs**, **3. Generate Bills**.
- **Tenant Bills:** search **Search tenant, room, utility...**; filters; **Mark as Sent** / **Mark as Paid** / **Mark as Overdue** / **Update Status**.
- No export/print on these tabs.
- Building-wide equal-split without meters is **Split a utility bill across rooms**.

## Done when
After refresh **Tenant Bills** lists a row per tenant. Amounts match the calculator.

## Watch out for
Pick a building first. Usage-based needs meter readings. **Generate Tenant Bills** is separate from **Calculate Allocation** — calculate first.
