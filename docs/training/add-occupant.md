# Job: Add a roommate / occupant

**Replaces:** A handwritten extra name on the Excel tenant row (spouse, child, relative — not the lease holder).

**Who does this:** Office admin (tenant can also add occupants in the portal)

**When:** Someone else lives in the unit besides the person on the lease.

## Steps
1. Sidebar **Tenants** → open the tenant → **Profile**. Under **Occupants**, click **Add Occupant** (opens the occupied room). Or: **Properties** → open that room.
2. Under **Current Tenant**, click **Add Occupant**.
3. Fill **First Name**, **Last Name**, and **Move-in Date**. Click **Add Occupant**.

## Done when
Toast **Occupant added successfully!** After refresh the name is on the room and on the tenant **Occupants** list.

## Watch out for
The unit must already have a current tenant. Tenant profile **Add Occupant** only jumps to the room — the form is on the room. Occupant actions (⋯) on the tenant list do not edit yet; change occupants from the room. Portal path: **Profile** → **Occupants**.
