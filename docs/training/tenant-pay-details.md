# Job: Put the GCash / bank number on Pay online

**Replaces:** Sending the office GCash number by chat every time a tenant asks how to pay.

**Who does this:** Office admin

**When:** Before tenants use portal **Pay now**. After the number or account name changes.

## Steps
1. Sidebar **Payments** → **Tenant pay details** (`/admin/settings?tab=payments`). (Header gear → tab **Tenant payments** is the same page.)
2. Fill **Payment phone number** (required). Optional: **Account name**, **Bank name (optional)**, **Bank account number (optional)**, **Instructions shown to tenants**.
3. Under **Accepted methods** tick **GCash**, **Maya**, **Bank transfer**, and/or **Other e-wallet**. Click **Save payment details**.

## Also on this page
**This tab**
- Heading **Tenant payment destination**.
- Alert if empty: **Tenants cannot Pay online yet**.
- Placeholder **09XXXXXXXXX**. Hints: **GCash / Maya / mobile number that receives tenant payments**, **Name on the GCash / bank account**, **e.g. BPI, BDO**.
- Saving: **Saving...**. Success: **Payment details saved** / **Tenants can now see where to send GCash / transfers.**
- No search / list / export on this tab.

**Other Settings tabs** (header gear → `/admin/settings`)
- **Notifications** — **In-app** / **Email** per category.
- **Security** — **Two-Factor Authentication**, **Session Timeout**, **Change Password**.
- **Preferences** — Language, Timezone, Currency, Date Format.
- **System** — **Enable tenant portal**, **Enable late-fee penalties**, nearby map cache, **Clear Cache**, **Export Data**.
- Footer **Save Settings** on non-payments tabs.
- See **Set office preferences**.

**Related**
- Payments list banner **Tenant Pay now is blocked** → **Add tenant pay details**.
- This does not record a payment.

## Done when
You see **Payment instructions saved — tenants will see these on Pay.** After refresh the same number is still there. A tenant on **Pay online** sees that phone / account.

## Watch out for
**Payment phone number** is required to save. If this is empty, portal **Pay now** is blocked. Use **Collect rent** or **Confirm a receipt** after they pay.
