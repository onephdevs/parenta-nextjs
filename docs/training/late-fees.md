# Job: Turn on and apply late fees

**Replaces:** TBD - ask client (Excel ledger did not run automatic penalties).

**Who does this:** Owner / office admin

**When:** You have decided to charge overdue rent. Off by default — prefer **Negotiate due date** on the invoice.

## Steps
1. Settings → **System**: tick **Enable late-fee penalties**. **Save Settings**.
2. Open `/admin/financial/late-fees/settings` (from the financial hub **Late fees**, not the sidebar). Save penalty rules.
3. Open `/admin/financial/late-fees/apply`. **Calculate Eligible Fees**, then **Apply Late Fees**. Confirm **Apply late fees?**

## Also on this page
- Apply page title **Late Fee Application**. **Dry run** before apply.
- Alert **Late fees are disabled** if the System checkbox is off.
- Invoice detail: **No late-fee penalties — agree a new deadline when rent is delayed, or apply a discretionary discount.**
- Payment gateways are a different hub card (**Test Mode**).

## Done when
After refresh, overdue invoices show the fee and **Payments** Type **Penalty** can collect it.

## Watch out for
If **Enable late-fee penalties** is off, Apply will not charge. **Apply Late Fees** is not a dry run — use **Dry run** first.
