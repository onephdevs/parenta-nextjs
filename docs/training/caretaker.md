# Job: What a caretaker can (and cannot) do

**Withdrawn (2 Sep 2026).** Caretaker is not a separate office role. Create an office login with [Add an office login](./add-office-login.md). They get the same admin access as everyone else (Dashboard, Payments, Reports, Users).

Staff who should only work repairs still use the **Staff** portal (`/staff`), which is a different role — not caretaker.
