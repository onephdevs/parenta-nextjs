# Job: Work a repair ticket

**Replaces:** A Messenger thread about a leak or broken fixture, with no status in the office.

**Who does this:** Office admin

**When:** A tenant submitted **New ticket**, or you see an **Open** request.

## Steps
1. Sidebar **Maintenance** (`/admin/maintenance`). Open a row (or use **Open pipeline** for the Tasks board).
2. Set **Status** (**Open**, **In Progress**, **Resolved**, **Cancelled**) and **Priority** (**Low**, **Medium**, **High**, **Urgent**). Optional: **Scheduled Date**, **Completed Date**, **Assigned To**, **Internal notes**.
3. Click **Save Changes**.

## Also on this page
**Maintenance Requests list**
- Cards: **Total Requests**, **Open**, **In Progress**, **Resolved**.
- **Search** — **Ticket, title, tenant, building…**
- Filters: **Status** (**All Status**, **Open**, **In Progress**, **Resolved**, **Cancelled**); **Priority** (**All Priority**, **Urgent**, **High**, **Medium**, **Low**); **Category** (**All Categories**, **Plumbing**, **Electrical**, **HVAC**, **Appliance**, **Structural**, **Other**).
- Table **Maintenance requests**. **Discussion** on the detail pane.
- **Open pipeline** — Tasks maintenance board.
- No **New ticket** / **Create Request** on this page. No delete button. No export / print / bulk / sort.
- Pagination if the list uses it (scroll the table if not).

**Create from elsewhere**
- Dashboard / property rail **Maintenance** opens **Create Request** (details, location, priority).
- Tenant portal **New ticket**.
- Properties → building **Maintenance** tab: **Add Request**, **View all**.

## Done when
After refresh the list shows the new **Status**. **Resolved** matches the pipeline **Resolved** column.

## Watch out for
This page has no **New ticket** button. Do not use **Cancelled** unless the work will not happen.
