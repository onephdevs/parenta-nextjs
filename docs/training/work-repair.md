# Job: Work a repair ticket

**Replaces:** A Messenger thread about a leak or broken fixture, with no status in the office.

**Who does this:** Office admin

**When:** A tenant submitted **New ticket**, or you see an **Open** request.

## Steps
1. Sidebar **Maintenance** (`/admin/maintenance`). Open a row (or use **Open pipeline** for the Tasks board).
2. Set **Status** (**Open**, **In Progress**, **Resolved**, **Cancelled**) and **Priority** (**Low**, **Medium**, **High**, **Urgent**). Optional: **Scheduled Date**, **Completed Date**, **Assigned To**, **Internal notes**.
3. Click **Save Changes**.

## Done when
After refresh the list shows the new **Status**. **Resolved** matches the pipeline **Resolved** column.

## Watch out for
This page has no **New ticket** button. Tenants create tickets in the portal; the dashboard rail can also create one. Do not use **Cancelled** unless the work will not happen.
