# Job: File a contract or ID in Documents

**Replaces:** A folder of IDs and contracts, or files sitting in chat.

**Who does this:** Office admin

**When:** You have a file that belongs on the property or tenant, not only on the tenant Documents tab.

## Steps
1. Sidebar **Documents** (`/admin/documents`). Click **Upload document**.
2. Add **Files**, **Document name**, **Category**, **Type**, optional **Property** / **Tenant**, **Expiry date**. Optional camera: **Take document photo**.
3. Click **Upload** (or **Upload {n} files**).

## Also on this page
- Cards: **Total documents**, **Pending signature**, **Expiring soon**, **Unlinked**.
- **Manage Categories** → `/admin/documents/categories`.
- **Search** — **Filename, tenant...**
- Filters: **Category** (**All Categories**), **Building**, **Status** (**All Status**, **Signed**, **On file**, **Expiring soon**, **Needs review**).
- Row: **View**, **Download**, **Edit**, **Delete** (confirm **Delete document?**). Pagination.
- Bulk when selected: **Clear selection**, **Categorize**, **Download ZIP**, **Delete**. Dialog **Bulk Categorize Documents**.
- No column sort. No print (except tenant-tab / designer).
- Sidebar children: **Lease Designer**, **Templates** (designer list). Generating a lease PDF for a tenant is **Issue or store a lease document**.

## Done when
After refresh the file is in the list (linked to the tenant/property if you set those). **Download** still works.

## Watch out for
**Document name** and a file are required. **Not linked** files show under **Unlinked** — attach a tenant or property if you will need to find them later.
