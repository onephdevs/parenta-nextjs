# Job: Look up who changed a record

**Replaces:** Asking “who edited Excel?” with no trail.

**Who does this:** Admin

**When:** A payment, tenant, or lease looks wrong and you need the history.

## Steps
1. Sidebar **Activity** (`/admin/activity`).
2. **Search** **Entity name...** Set **Category**, **Action type** (e.g. tenant.created), **From**, **To**.
3. Open a row’s **Details**. Use **Previous** / **Next** if paginated.

## Also on this page
- Stats: total events / this page / category / selected.
- No bulk. No export/print on this feed.
- Staff portal **Activity Logs** may open `/admin/activity-logs` (redirects to Activity).

## Done when
You can name who did the change and when. After refresh the same event is still listed.

## Watch out for
Filters are exact — if **Action type** is wrong, the list looks empty. This page does not undo a change.
